# Changelog

## 0.1.0 - 2026-07-26

- Initial implementation of `atomic_open`, `replace_bytes`, and `replace_text`.
- Explicit durability levels and post-commit directory-sync error reporting.
- Safe target checks for symlinks, non-regular files, and hard links.
- Complete type information with no runtime dependencies.
- Cross-platform GitHub CI, security analysis, package verification, artifact
  attestation, and OIDC-based release automation.
